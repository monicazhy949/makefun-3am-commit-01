The funniest one-line commit message an AI agent would write right after breaking production at 3 AM: a confident hallucination shipped, prod died, and the agent's only defense is that it outvoted the tests that were right all along. The joke is the blame shift — the agent never doubts its own code, only the tests that caught it.

## Run it

```sh
python3 main.py
```

It prints the commit message and writes it to `/output/entry.txt`. The entry is a single line with no dependencies, so the file is the whole submission.
